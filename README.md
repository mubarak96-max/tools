# FindBest Tools

FindBest Tools is a comprehensive collection of free online tools and calculators designed to help professionals, developers, and homeowners simplify complex tasks. From marketing and SEO to finance and construction, we provide accurate, fast, and easy-to-use utility tools.

## Project Structure

This project is built with **Next.js 15 (App Router)** and **Tailwind CSS**.

- `src/app/` - Contains all tool pages and blog guides.
- `src/components/` - Reusable UI components and tool-specific logic.
- `src/lib/` - Shared utilities for SEO, formatting, and calculations.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Then, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the application.

## Deployment

The project is optimized for deployment on Vercel.

```bash
npm run build
```
